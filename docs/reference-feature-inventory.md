# Umbra Feature Inventory & Parity Strategy

This inventory catalogs every functional capability implemented in Umbra (`myguiproxy`), documents its exact source files and implementation details, and outlines the implementation strategy and parity status for **Lightgui**.

| Feature Name | Umbra Source Files | Umbra Implementation Details | Lightgui Strategy | Parity Status |
| :--- | :--- | :--- | :--- | :--- |
| **Sing-box Process Spawning** | `src-tauri/src/singbox/process.rs`, `job.rs` | `tokio::process::Command` with `CREATE_NO_WINDOW`, piped stdout/stderr, bounded to kernel Job Object via `CreateJobObjectW` and `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`. | Reuse Win32 Job Object logic in `lightgui-core::singbox::runner`. Retain zero-orphan guarantee on force kill. | **Full Parity** |
| **Config Generation** | `src-tauri/src/singbox/config.rs` | Pure Rust in-memory AST generation producing `GeneratedConfig` JSON Value, assigning outbound tags, selector group, urltest group, inbounds (mixed or tun), DNS, and routing rules. | Port config generator directly to `lightgui-core::singbox::config`. Identical JSON output structure compatible with sing-box 1.13+. | **Full Parity** |
| **Config Validation** | `src-tauri/src/singbox/process.rs` | Executes `sing-box check -c generated.json` before run; intercepts stderr, stores error log, extracts `short_reason` (first line $\le 160$ chars). | Port to `lightgui-core::singbox::process::check_config`. Populates toast/error dialog on failure. | **Full Parity** |
| **Startup Verification** | `src-tauri/src/singbox/process.rs` | Polls `child.try_wait()` every 100ms for 1500ms (`STARTUP_CONFIRM`) to capture immediate crashes (port collision, driver failure). | Identical 1.5s non-blocking poll in background worker thread. | **Full Parity** |
| **Crash Backoff & Supervision** | `src-tauri/src/singbox/process.rs` | Async supervisor loop. On core crash: auto-restart with backoff (1s, 3s, 9s), max 3 attempts. Resets attempt counter after 60s uptime. Restores proxy if failed. | Ported to background supervisor thread in `lightgui-core`. Dispatches status changes via IPC to tray and settings. | **Full Parity** |
| **Graceful Teardown** | `src-tauri/src/singbox/process.rs` | 3s SIGTERM grace (`start_kill`), fallback to hard kill (`kill`). 12s join timeout. Reverts system proxy before process exit. | Identical graceful kill sequence implemented via standard process handles. | **Full Parity** |
| **Clash API Controller** | `src-tauri/src/singbox/clash_api.rs` | Binds `127.0.0.1:<port>` with random bearer secret token. Used for stats, selector switching, and delay testing. | Retained in `lightgui-core::singbox::clash_api`. Managed dynamically. | **Full Parity** |
| **Hot Server Switching** | `src-tauri/src/singbox/clash_api.rs` | `PUT /proxies/proxy` with `{"name": tag}`. Zero downtime switch without restarting core or dropping connections. | Ported to `lightgui-core`. Tray menu allows 1-click server switching via this endpoint. | **Full Parity** |
| **Traffic Monitoring (Proxy)** | `src-tauri/src/singbox/clash_api.rs` | WebSocket `ws://127.0.0.1:<port>/traffic`. Frame-per-second parsing (`up`, `down`). `TotalsAccumulator` buffers and flushes to disk every 15s. | Lightweight background WebSocket client or HTTP stream in `lightgui-core`. Disk flush throttled to 15s. | **Full Parity** |
| **Traffic Monitoring (TUN)** | `src-tauri/src/net/traffic.rs` | Direct Windows IP Helper `GetIfTable2(&mut table)` query for interface alias `"umbra-tun"`. Reads `OutOctets` and `InOctets`. | Implemented in `lightgui-core::net::traffic` using `windows-sys` or `windows::Win32::NetworkManagement::IpHelper`. | **Full Parity** |
| **TCP Latency Ping** | `src-tauri/src/net/ping.rs` | Asynchronous TCP connect latency probe over 2 attempts with 3s timeout. Concurrency limit 8. Persists `last_ping_ms`. | Ported to `lightgui-core::net::ping`. High-efficiency socket probes without core dependency. | **Full Parity** |
| **Clash Delay Test** | `src-tauri/src/singbox/clash_api.rs` | `GET /proxies/<tag>/delay?timeout=5000&url=<url>`. Measures end-to-end proxy transit latency through core. | Available via `lightgui-core::singbox::clash_api::delay`. Triggered on demand in settings. | **Full Parity** |
| **Subscription Fetching** | `src-tauri/src/subscription.rs` | HTTP GET with `v2rayN/7.13 Umbra/<ver>` User-Agent, 20s timeout, `.no_proxy()`. Attaches HWID headers (`x-hwid`, `x-device-os`, `x-ver-os`, `x-device-model`). | Ported to `lightgui-core::subscription`. Native HTTP client using `reqwest` (rustls backend). | **Full Parity** |
| **Subscription Body Decoding** | `src-tauri/src/subscription.rs` | UTF-8 BOM strip, plain URI list detection, standard/URL-safe base64 decoding with padding recovery. Rejects Clash YAML and JSON. | Identical decoder logic ported to `lightgui-core::subscription::decode`. | **Full Parity** |
| **Anti-Placeholder Guard** | `src-tauri/src/subscription.rs` | Detects `0.0.0.0:1` / `127.0.0.1:1` dummy nodes returned by Remnawave panels when device limit reached. Intercepts `x-hwid-*` headers. | Exact guard ported to `lightgui-core`. Prevents storing non-functional placeholder nodes. | **Full Parity** |
| **Subscription Metadata** | `src-tauri/src/subscription.rs` | Extracts `subscription-userinfo` (quota), `profile-title` (base64/utf-8), `profile-update-interval`, `support-url`. | Full metadata extraction preserved in `lightgui-core::models`. Displayed in settings dialog. | **Full Parity** |
| **VLESS Reality / Flow** | `src-tauri/src/parser/vless.rs` | Parses `vless://` links: UUID, host, port, security (`reality`, `tls`, `none`), `pbk`, `sid`, `fp` (uTLS), flow `xtls-rprx-vision`. | Exact parser ported to `lightgui-core::parser::vless`. Same strict URI query decoding. | **Full Parity** |
| **VLESS Transports** | `src-tauri/src/parser/vless.rs` | Supports `tcp`, `ws` (cleans `?ed=`), `grpc` (`serviceName`), `httpupgrade`. Rejects `xhttp`/`splithttp`. `xudp` packet encoding. | Ported to `lightgui-core::parser::vless`. Full transport matrix preserved. | **Full Parity** |
| **Hysteria2 Protocol** | `src-tauri/src/parser/hysteria2.rs` | Parses `hysteria2://` and `hy2://` links: password, port, SNI fallback, insecure flag, ALPN, `obfs=salamander`. Rejects multi-port. | Exact parser ported to `lightgui-core::parser::hysteria2`. | **Full Parity** |
| **Additional Protocols** | `src-tauri/src/parser/mod.rs` | Extensible `LinkParser` trait. Currently rejects VMess, Trojan, Shadowsocks with clear unsupported errors. | Ported to `lightgui-core::parser`. Extensible for future protocols (Trojan/Shadowsocks). | **Full Parity** |
| **Routing Rules Engine** | `src-tauri/src/singbox/config.rs` | Rules by Process Name/Path, Domain (Suffix, Exact, Keyword, Regex), IP CIDR. Actions: Proxy, Direct, Block (`reject`). | Ported to `lightgui-core::models` and `config.rs`. Full routing feature set preserved. | **Full Parity** |
| **Discord UDP Preset** | `src-tauri/src/singbox/config.rs` | Bypasses UDP traffic for `Discord.exe`, `DiscordCanary.exe`, `DiscordPTB.exe` directly, avoiding XUDP head-of-line delay. | Toggleable preset in `lightgui` settings and config generator. | **Full Parity** |
| **Private IP Bypass Preset** | `src-tauri/src/singbox/config.rs` | `ip_is_private: true -> direct`. | Standard built-in rule in config generator. | **Full Parity** |
| **Russian Anti-Block Presets** | `src-tauri/src/singbox/config.rs` | Downloads remote binary rule sets `geosite-category-ru.srs` and `geoip-ru.srs` with 7-day refresh interval. | Preserved in `lightgui-core`. User toggleable. | **Full Parity** |
| **Process Picker / Enumerator** | `src-tauri/src/commands/processes.rs` | Enumerates visible windows via `EnumWindows`, cross-references `CreateToolhelp32Snapshot`, resolves paths via `QueryFullProcessImageNameW`. | **Lazy-loaded** in `lightgui-settings` ONLY when the process routing tab is opened. Zero background cost. | **Full Parity (Optimized)** |
| **WinINET System Proxy** | `src-tauri/src/proxy/system_proxy.rs` | Modifies `HKCU\...\Internet Settings` (`ProxyEnable`, `ProxyServer`, `ProxyOverride`). Broadcasts via `InternetSetOptionW`. Pre-write backup. | Ported to `lightgui-core::net::system_proxy`. Registry backup and startup recovery retained. | **Full Parity** |
| **TUN Virtual Adapter** | `src-tauri/src/singbox/config.rs` | Inbound `tun` using Wintun driver. Auto-assigned addresses, MTU (default 9000), `strict_route`, `stack`. | Identical sing-box TUN inbound generated. Clean kernel teardown on process close. | **Full Parity** |
| **UAC Elevation Relaunch** | `src-tauri/src/proxy/elevation.rs` | Detects token elevation (`GetTokenInformation`). Relaunches self elevated via `ShellExecuteW(..., "runas", ...)`. | Preserved in `lightgui`. Prompts user with native UAC dialog when switching to TUN mode. | **Full Parity** |
| **Windows Autostart** | `src-tauri/src/commands/settings.rs` | Manages `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` registry string. | Implemented directly via `winreg` in `lightgui-core` without third-party plugin bloat. | **Full Parity** |
| **Hardware ID Generation** | `src-tauri/src/hwid.rs` | Reads `MachineGuid` from 64-bit registry; hashes with SHA-256 and `"umbra-hwid-v1"` salt; queries hardware model from registry. | Ported directly to `lightgui-core::hwid`. Fully compatible with existing panel licenses. | **Full Parity** |
| **Atomic JSON Storage** | `src-tauri/src/storage.rs` | Reads/writes `settings.json` and `profiles.json` atomically using `.tmp` write and replace rename. | Ported to `lightgui-core::storage`. Robust against unexpected system shutdowns. | **Full Parity** |
| **Schema Migration (V1->V2)** | `src-tauri/src/storage_migration.rs` | Migrates legacy flat profile store to version 2 polymorphic schema. | Ported to `lightgui-core::storage::migration`. Can read existing Umbra `%APPDATA%` files. | **Full Parity** |
| **In-Memory Log Ring Buffer** | `src-tauri/src/singbox/process.rs` | 2000-line ring buffer (`VecDeque<LogLine>`), timestamped, level normalized (`trace`, `debug`, `info`, `warn`, `error`). | In-memory ring buffer in `lightgui-core`. Tail fetched on-demand when Settings Log tab opened. | **Full Parity** |
| **System Tray Icon & Menu** | `src-tauri/src/tray.rs` | Custom icons for connected/disconnected state. Context menu: Show, Connect/Disconnect, Mode toggle, Active Server, Quit. | Implemented via pure Win32 `Shell_NotifyIconW`, `CreatePopupMenu`, and `TrackPopupMenuEx`. | **Full Parity (100x Lighter)** |
| **Settings UI** | `src/pages/Settings.tsx`, `App.tsx` | React 19 web page with tabs (General, Servers, Routing, Logs). Rendered inside WebView2. | **Native Win32 GUI dialog/window** (`lightgui-settings.exe`) using Win32 Common Controls. Closed = 0 MB RAM. | **Full Parity (Zero WebView2)** |
